# Course Description

*Last edited: 22 September 2026*

## Course Title

**First Principles of Programming for Vibe Coding**

## Central Problem

Generative AI has made it possible for people with little or no programming experience to produce code, but it has not given them the conceptual knowledge needed to reason about, specify, evaluate, debug, modify, and safely reuse that code.

## Problem Statement

AI-assisted coding tools allow people with limited programming experience to generate increasingly sophisticated software, but these users often lack the foundational programming and software-development concepts needed to specify what they want, understand what has been generated, diagnose problems, evaluate solutions, and iteratively improve their software.

Existing introductory programming courses largely assume that learners need to write code themselves and therefore devote substantial attention to language-specific syntax and implementation. Conversely, guidance on AI-assisted coding often focuses on prompting or particular AI tools. There is therefore a gap for tool- and language-agnostic training that teaches the minimum conceptual foundations of programming and software systems needed to use AI coding tools effectively and responsibly.

## Target Audience

A researcher, research-support professional, student, or other domain expert who has little formal programming training but is already using or wants to use AI coding assistants to create scripts, analyses, automations, websites, dashboards, or small applications.

:::::::::::::::::::::::::::::::::::::: keypoints

- AI can generate code, but learners still need to specify, understand, evaluate, and improve what it produces.
- This course focuses on transferable programming and software-development concepts rather than a single language or AI tool.
