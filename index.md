# First Principles of Programming for Vibe Coding

---
### Course Description

Generative AI has made it possible for people with little or no
programming experience to produce code, but it has not given them
the conceptual knowledge needed to reason about, specify, evaluate,
debug, modify, and safely reuse that code.

### About This Course

This course teaches the foundational concepts of programming
and software development needed to work effectively with
AI coding assistants.

Unlike traditional programming courses, it focuses on
computational thinking, understanding generated code,
debugging, and evaluating AI-generated solutions rather than
memorizing programming syntax.

### Target Audience

This course is designed for researchers, research-support
professionals, students, and domain experts with little
formal programming experience.

### What You Will Learn

- Turn ideas into computational workflows.
- Break problems into smaller tasks.
- Understand variables, state, conditions, and loops.
- Write pseudocode and specifications.
- Work effectively with AI coding agents.
- Evaluate, debug, and improve AI-generated software.
- Trace inputs through generated functions and verify a focused change.
- Explain how a browser, server, and database exchange and store information.
- Specify validation, persistence, access, and failure behaviour for a small app.

exercises. Prepared examples support participation without an AI account, and
text-based evidence is available when local tools cannot run. Timings are initial
estimates for pilot teaching.
